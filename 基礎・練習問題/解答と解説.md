## 第1部　読む問題

### 問1
```
Hello 
3.14
```
- 1 行目は `"Hello "` なので**末尾に半角スペース**が入る。ここは減点ポイント。
- `3.14` は `"3.14"` と文字列として `print` しているので、そのまま表示される。

### 問2
```
上田の所持金：5円
上田の所持金：5円
```
- 1 行目は `+` で連結。数値 `money` はそのままでは連結できないので `str(money)` で文字列化している。
- 2 行目は `.format(name, money)` が `{}` に順番にはめ込まれる。`money` は数値でも自動で文字列化される。

### 問3
```
0番目から2番目の要素： ['a', 'b', 'c']
2番目以降の要素: ['c', 'd', 'e']
一つ飛ばしでリストを作成： ['a', 'c', 'e']
```
- スライス `[0:3]` は**3 番目を含まない**（0,1,2）。
- `[2:]` は添字 2 の要素（`'c'`）から最後まで。
- `[0::2]` は「開始:終了:ステップ」。ステップ 2 で 1 つ飛ばし。

### 問4
- **3 回**繰り返す（要素が 3 つ）。
```
appleは美味しい
bananaは美味しい
cheryは美味しい
```
- 元ファイルは `"chery"`（`cherry` ではない）。**ファイルの表記どおり**に答えるのが正解。

### 問5
- 実行できるのは **(a) `python3 fruits.py`** のみ。
- `./fruits.py` は「そのファイル自身をプログラムとして実行する」命令なので、
  シバン行と実行権限が必要。`fruits.py` は両方欠けているため失敗する。
  （`ls -l` が `-rw-r--r--` で、実行権限 `x` が無いことでも確認できる）

## 第2部　Linux で Python を使う問題

### 問6
1. **シバン行**：このファイルを「どうやって実行するか」を OS に伝える 1 行目。
   `#! /usr/bin/python3` は「`/usr/bin/python3` で実行せよ」という意味。
   これがあると `./hello.py` のように直接実行できる。
2. **`python3 hello.py`**：`python3` にファイルを**引数として渡して**実行する。
   シバンや実行権限が無くても動く。
3. **`./hello.py`**：hello.py を**コマンドとして直接実行**する。
   シバン行と実行権限（`x`）が必要。先頭の `./` は「カレントディレクトリの」という意味。
4. **`chmod +x hello.py`**：hello.py に実行権限（`x`）を付ける。
   `chmod` = change mode。`+x` = 実行許可を追加。

### 問7
1. `-rwxr-xr-x` は 10 文字。先頭 `-` は「通常のファイル」。
   続く 9 文字を 3 文字ずつ読む。

   | 対象 | 表記 | 意味 |
   |---|---|---|
   | 所有者 | `rwx` | 読み・書き・実行すべて可 |
   | グループ | `r-x` | 読み・実行可、書き不可 |
   | その他 | `r-x` | 読み・実行可、書き不可 |

2. ```
   chmod +x fruits.py
   ```
   その後 `./fruits.py` で実行できる。
   ※ ただし `fruits.py` はシバン行が無いので、実際に直接実行するには
   1 行目に `#! /usr/bin/python3` を追加する必要がある。

### 問8
1. `python3 fruits.py` のように **python3 に渡して実行**する。
2. 1 行目に **シバン行 `#! /usr/bin/python3` を追加**し、`chmod +x fruits.py` してから `./fruits.py` で実行する。

### 問9
1. `import sys`
2. 次のリストになる（先頭はスクリプト名）。
```
['sample.py', 'apple', 'banana']
```
そのため、実際の引数は `sys.argv[1:]` で取り出す。

## 第4部　発展問題

### 問14（`arg_sum.py`）
```python
#! /usr/bin/python3
import sys

total = 0
for a in sys.argv[1:]:        # 先頭はスクリプト名なので 1 番目以降
    total = total + int(a)    # 文字列を数値に変換
print("合計は " + str(total) + " です")
```
実行：
```
$ python3 arg_sum.py 3 5 7
合計は 15 です
```
- `int()` を忘れると `"3" + "5"` のように文字列連結になりエラーや誤動作になる。

### 問15（`count.py`）
```python
#! /usr/bin/python3
import sys

lines = 0
apple = 0
for line in sys.stdin:          # 標準入力から 1 行ずつ
    lines = lines + 1
    if line.strip() == "apple":
        apple = apple + 1
print(str(lines) + " 行中 apple は " + str(apple) + " 回")
```
実行：
```
$ printf "apple\nbanana\napple\n" | python3 count.py
3 行中 apple は 2 回
```
- `printf "apple\nbanana\napple\n"` は改行付きの 3 行を出力する。`for line in sys.stdin:` はこの 3 行を 1 行ずつ読む。
- `line.strip()` は行末の改行 `\n` を除去するために使う。これが無いと `"apple\n" == "apple"` が偽になる。

### 問16（仕上げ手順）
```bash
# 1. シバンを付ける（ファイルの 1 行目）
#    （エディタで先頭に追加）

# 2. 実行権限を付ける
chmod +x ファイル名.py

# 3. 権限を確認
ls -l ファイル名.py

# 4. 直接実行
./ファイル名.py

# 5. どちらでも同じ結果になることを確認
python3 ファイル名.py
```

## 学習のポイント（総まとめ）

| 項目 | キーワード | つまずきやすい所 |
|---|---|---|
| 実行 | シバン / `chmod +x` / `./` | 権限 `x` が無いと `./` で失敗 |
| 表示 | `print()` | 全角・半角、末尾スペース |
| 変数 | `str()` / `.format()` | 数値と文字列はそのまま連結できない |
| リスト | `[a:b]` / `[a:b:c]` | 終了位置の要素は含まない |
| 反復 | `for` / インデント | タブとスペースの混在でエラー |
| Linux | `ls -l` / パイプ `|` / `sys.argv` | `sys.argv[0]` はスクリプト名 |

エラーが出たら、まず**最後の 1 行**と**行番号**を読み、
`ls -l` や `python3 -v` で環境を確認するのが基本です。
