# 第6回：Bashでリグレッションテスト

`test.bash` は、リポジトリ直下の `plus-stdin.py` に標準入力からデータを渡し、出力と終了ステータスを確認します。資料では対象を `plus` に改名していますが、このリポジトリでは元のファイル名のまま使います。合計の期待値も、既存の小数表記に合わせています。

リポジトリ直下で実行します。

```console
$ ./第6回/test.bash
OK
$ echo $?
0
```

| 標準入力 | 期待する標準出力 | 終了ステータス |
| --- | --- | --- |
| `seq 5`（1～5を1行ずつ） | `15.0` | `0` |
| `あ` | なし | `1` |
| 空行1行（改行のみ） | なし | `1` |
| 入力0行（`/dev/null`） | `0.0` | `0` |

`$(...)` で標準出力を変数に入れ、直後に `$?` を保存します。`$(...)` は末尾の改行を取り除くので、比較には末尾の改行を含めません。異常入力で出る標準エラーは比較の対象外です。

期待値と違うときは `ng` が `NG at Line ...` と行番号を表示します。テストスクリプト自体は、全項目が通れば `0`、一つでも失敗すれば `1` で終了します。
